# Cupd. landing site

Static HTML/CSS landing site for `cupd.co.uk`.

## Files

- `index.html` — landing page
- `privacy.html`
- `terms.html`
- `support.html`
- `delete-account.html`
- `styles.css`

## Hosting options

This site does **not** require Vercel, Next.js, a database, Node or any AI tooling.

Recommended simple options:

### GitHub Pages
1. Create a new GitHub repo, e.g. `cupd-website`.
2. Upload these files to the repo root.
3. GitHub → Settings → Pages.
4. Deploy from `main` branch / root.
5. Add `cupd.co.uk` as the custom domain.
6. GitHub will show the DNS records to add in GoDaddy.

### Cloudflare Pages
Connect the GitHub repo to Cloudflare Pages and deploy as a static site.
No build command is required. Output directory is the repo root.
